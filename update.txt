Blockable Block Deigner 업데이트 내역
현재 버전: v1.2.1

[주요 기능 추가]
- 사용자 정의 Block Type과 색상 관리 기능
- 클릭 방식의 블록 모양 설계와 회전·반전 설정
- 블록 자체 효과 및 조합 완성 효과 편집
- 동일 블록과 서로 다른 블록을 이용한 조합식 설계
- 정확한 블록, Type, 색상, 태그, 모양 전용 조합 슬롯
- 조합별 조건부 보너스와 프로젝트 공통 색상 시너지
- 같은 색, 서로 다른 색, 특정 색 개수, 색상 구성, Type, 태그 조건
- 효과별 일반 입력 폼과 한글 표시 이름
- 버프·상태의 한글 이름, 영문 ID, 수치, 지속 턴 입력
- Linux 및 Windows 실행 방법과 사용자 매뉴얼
- UTF-8 JSON 저장·불러오기와 이전 규칙 파일 호환

[사용성 개선]
- 효과의 순서를 '효과 적용 순서'로 명확화
- JSON을 몰라도 효과 값을 입력할 수 있도록 입력 폼 개선
- 모든 조합 슬롯을 한 번에 모양 전용 조건으로 변경
- 블록과 조합식 목록에 현재 입력값 적용용 저장 버튼 추가
- 상단 파일 저장 전에 현재 편집 내용을 자동 반영
- 블록 ID 변경 시 기존 조합식 참조 자동 갱신
- 프로젝트 ID의 첫 글자·언어·대소문자 제한 완화
- 분리된 블록 모양과 서로 떨어진 조합 구조 허용

[버그 수정 및 안정성]
- 추가·삭제 후에만 목록에 현재 입력값이 반영되던 현상 개선
- 오류가 있어도 초안으로 저장하고 다시 열 수 있도록 개선
- 초안에 validation_status와 오류·경고 개수 기록
- 블록 인스턴스 겹침, 잘못된 참조, 효과 값 검증 강화
- 좌표 정규화와 원자적 파일 저장으로 파일 손상 방지
- 기존 JSON의 내장 효과 입력 메타데이터 자동 보강
- 기본 규칙 저장 파일명을 blockable_block_design.json으로 통일
- Python 패키지 경로를 src/blockable_block_deigner로 통일

[참고]
- 이 파일은 변경 내역을 구체적인 과거 버전별로 구분하지 않는다.
- 현재 배포 및 문서의 기준 버전은 v1.2.1이다.
