Blockable Block Designer 업데이트 내역
현재 버전: v1.2.3

[주요 기능 추가]
- 사용자 정의 Block Type과 색상 관리 기능
- 클릭 방식의 블록 모양 설계와 회전·반전 설정
- 블록 자체 효과 및 조합 완성 효과 편집
- 동일 블록과 서로 다른 블록을 이용한 조합식 설계
- 정확한 블록, Type, 색상, 태그, 모양 전용 조합 슬롯
- 조합별 조건부 보너스와 프로젝트 공통 색상 시너지
- 같은 색, 서로 다른 색, 특정 색 개수, 색상 구성, Type, 태그 조건
- 효과별 일반 입력 폼과 한글 표시 이름
- 버프·상태의 한글 이름, 영문 ID, 수치, 지속 턴 입력
- Linux 및 Windows 실행 방법과 사용자 매뉴얼
- UTF-8 JSON 저장·불러오기와 이전 규칙 파일 호환

[사용성 개선]
- 효과의 순서를 '효과 적용 순서'로 명확화
- JSON을 몰라도 효과 값을 입력할 수 있도록 입력 폼 개선
- 모든 조합 슬롯을 한 번에 모양 전용 조건으로 변경
- 블록과 조합식 목록에 현재 입력값 적용용 저장 버튼 추가
- 상단 파일 저장 전에 현재 편집 내용을 자동 반영
- 블록 ID 변경 시 기존 조합식 참조 자동 갱신
- 프로젝트 ID의 첫 글자·언어·대소문자 제한 완화
- 분리된 블록 모양과 서로 떨어진 조합 구조 허용

[버그 수정 및 안정성]
- 추가·삭제 후에만 목록에 현재 입력값이 반영되던 현상 개선
- 오류가 있어도 초안으로 저장하고 다시 열 수 있도록 개선
- 초안에 validation_status와 오류·경고 개수 기록
- 블록 인스턴스 겹침, 잘못된 참조, 효과 값 검증 강화
- 좌표 정규화와 원자적 파일 저장으로 파일 손상 방지
- 기존 JSON의 내장 효과 입력 메타데이터 자동 보강
- 기본 규칙 저장 파일명을 blockable_block_design.json으로 통일
- Python 패키지 경로를 src/blockable_block_designer로 통일
- Codex 작업 지침을 docs 경로에 배치하고 프로젝트 변경 시 동시 갱신하도록 명문화

[참고]
- 이 파일은 변경 내역을 구체적인 과거 버전별로 구분하지 않는다.
- 현재 배포 및 문서의 기준 버전은 v1.2.3이다.
- 조합식에서 배치된 블록을 회전·반전 상태를 유지한 채 드래그 이동할 수 있다.
- 특정 색상을 지정하는 단일 속성 시너지를 추가했다.
- 공격·방어·회복 등 합산 수치에 음수 값을 사용할 수 있다.
- 블록과 조합식 목록에 위·아래·최상단·최하단 이동 기능을 추가했다.
- 효과명, ID, 설명과 입력값 형식을 관리하는 사용자 정의 효과 편집기를 추가했다.
- 추가 턴, 방어 획득, 매 턴 공격·방어·회복·상태이상 효과의 기본 정의를 추가했다.
- 조합식 선택 블록을 `R` 키로 CCW 90도 회전할 수 있다.
- 편집 중 블록 겹침을 허용하고 겹친 칸을 빨간색으로 표시하며, 겹침이 남으면 저장을 차단한다.
- 각 효과 값 편집 화면에서 드롭다운 아래의 `새 효과 만들기`로 정의를 즉시 추가할 수 있다.
- 효과 정의를 `blockable_effect_config.json`으로 가져오고 내보내 공유할 수 있다.
- Codex 작업 지침을 최신 `examples/blockable_block_design.json` 기준으로 갱신했다.
- Codex 작업 지침 파일명을 `BLOCKABLE_BLOCK_DESIGN_CODEX_INTERACTION_INSTRUCTION.md`로 대문자화했다.
- 새 디자인 JSON을 기준으로 Codex 지침서를 다시 작성하고 두 파일을 함께 다른 프로젝트에 적용하는 절차를 명문화했다.
- 공통 전투 효과 표준에 맞춰 기본 효과 ID·파라미터·대상·범위를 통일했다.
- 표준 상태와 사용자 정의 상태를 관리하고 `apply_status`에서 드롭다운으로 재사용할 수 있게 했다.
- 구버전 `apply_buff`, `gain_defense`, 이전 대상·상태 별칭을 불러오기/저장 시 최신 형식으로 자동 변환한다.
- 표준에 없는 효과 파라미터, 존재하지 않는 상태 ID, 조건부 필수 범위를 검사한다.
- 전투 효과 표준 문서를 본 게임이 소유하는 읽기 전용 기준으로 명문화했다.
- 의미가 명확히 같은 사용자 정의 효과를 표준 효과로 자동 통합하고, 확장되거나 애매한 효과는 보존한다.
문서 정리
- Codex 작업 지침 파일명의 `Insstruction` 오타를 `Instruction`으로 정정하고 관련 참조를 갱신했습니다.
